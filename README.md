# MiraProgrammer

**Kostenlose Software für Windows und Linux – ohne Veröffentlichung des Quellcodes.**

MiraProgrammer wird als **Freeware (Closed Source)** bereitgestellt. Die fertigen Programmdateien können kostenlos heruntergeladen und verwendet werden. Der Quellcode ist nicht Teil dieses Download-Repositories.

## Downloads

**[Alle Versionen herunterladen](https://github.com/OlgunBeyaz/MiraProgrammer/releases)**

| Betriebssystem | Datei | Nutzung |
| --- | --- | --- |
| Windows 64-Bit | `MiraProgrammer-Windows-Portable.zip` | ZIP entpacken und `MiraProgrammer.exe` starten |
| Linux 64-Bit | `MiraProgrammer-Linux.AppImage` | AppImage herunterladen, ausführbar machen und starten |

**Hinweis:** Die Download-Dateien erscheinen erst, nachdem eine Version unter **Releases** veröffentlicht wurde. Derzeit sind noch keine Programmdateien hochgeladen.

### Windows – Portable

1. Lade `MiraProgrammer-Windows-Portable.zip` aus der gewünschten Version unter **Releases** herunter.
2. Entpacke das ZIP-Archiv vollständig.
3. Starte `MiraProgrammer.exe`. Eine klassische Installation ist nicht erforderlich.

### Linux – AppImage

1. Lade `MiraProgrammer-Linux.AppImage` aus **Releases** herunter.
2. Wechsle im Terminal in den Downloadordner und führe Folgendes aus:

```bash
chmod +x MiraProgrammer-Linux.AppImage
./MiraProgrammer-Linux.AppImage
```

Abhängig von Distribution und Paketierung können zusätzliche Systembibliotheken erforderlich sein.

## Veröffentlichung neuer Versionen

1. Erstelle die ausführbaren Dateien lokal oder in einer **privaten** Build-Umgebung.
2. Öffne **Releases → Draft a new release**.
3. Vergib ein Tag, beispielsweise `v1.0.0`.
4. Lade die fertigen Dateien für Windows und Linux als **Release assets** hoch.
5. Veröffentliche das Release.

Veröffentliche hier **keine** Projektquellen, Build-Skripte mit Geheimnissen, Zugangsdaten oder privaten Schlüssel. Für den öffentlichen Download genügt dieses Repository mit README und Releases.
